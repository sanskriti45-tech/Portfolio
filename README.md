# Sanskriti's Interactive Portfolio 🚀

A personal developer portfolio designed to bring together creative web experiences, smooth animations, and AI-powered projects in one immersive interface.

### ✨ Features
- 🎨 Modern, cinematic design with expressive typography
- ⚡ Smooth transitions, scroll reveals, and interactive hover effects
- 💻 Custom interactive terminal with portfolio-specific commands
- 🗓️ Book-a-call integration for easy scheduling
- 🏎️ **F1 Race Predictor** — machine learning and race prediction
- ⚽ **FIFA Pulse AI** — AI-powered football project
- 🎙️ **VoiceCraft** — voice technology project
- 📱 Responsive layout for desktop, tablet, and mobile
- ♿ Accessibility-conscious interactions and reduced-motion support

### 🎯 Goal
To create a memorable digital portfolio that showcases my projects, technical skills, and approach to building useful, engaging software.
